## 延迟由什么决定

物理距离是硬性条件。光在光纤里往返 1000 公里大约多 10ms，香港到深圳的距离，决定了它天然比洛杉矶快一个数量级。线路是在这个基数上做优化：普通国际带宽绕路、跳数多，晚高峰容易丢包；CN2 GIA 是中国电信的精品承载网（AS4809），路由直、优先级高，批发成本也高。

## 按运营商和场景选线路

电信、联通用户优先 CN2 GIA。这条线路三网覆盖均衡，晚高峰丢包控制得好，代价是价格高。移动用户用 CMIN2 或 CMI 就够了，移动国际精品网对移动宽带的体验接近 GIA，价格却低一截。三网混合、预算又有限，可以选 BGP 多线加优化回程的方案，让每个运营商走相对顺的路由。

场景比线路参数更能决定你要不要多花钱。实时通信、游戏加速、音视频推流，延迟每降 10ms 都有感知，直接上 Pro 系列。普通建站、代理、轻量 API，Eyeball 或 T1 完全够用。以 DMIT 为例，香港 Eyeball 比 Pro 便宜约 25%，洛杉矶 Eyeball 和 Pro 同价但流量多 50%，这笔账怎么算取决于你对延迟有多敏感。

1. 用商家提供的测试 IP 跑双向 MTR，去程和回程分开看，别只看 ping。

3. 确认流量是单向还是双向计费，超量后是限速还是停机。DMIT 的规则是超量限速，T1 系列限到 100Mbps，香港和东京 T1 限到 50Mbps。

5. 香港机房免备案，即买即用；需要备案的域名和业务，别选错机房。

## 常见问题

**香港和洛杉矶的延迟差距有多大？**

香港到国内主要城市 20–50ms，洛杉矶 150–200ms。普通建站感知有限，实时通信、游戏、推流场景差距明显。用户在国内，香港优先；用户在欧洲或美洲，选对应地区机房。

**CN2 GIA 和 CMIN2 哪个更好？**

CN2 GIA 三网均衡、延迟低、稳定性好，带宽成本高。CMIN2 对移动用户体验最好，电信联通走 AS9929，整体延迟略高于 GIA，性价比更突出。电信联通为主选 GIA，移动为主选 CMIN2 或 CMI。

**流量超了会直接断网吗？**

多数商家是限速而不是停机。DMIT 超量后限速继续跑，可以买额外流量包解除；部分商家会按超出部分计费。购买前在套餐页或 FAQ 里确认计费方式。

**香港 VPS 需要备案吗？**

不需要。香港机房不涉及中国大陆 ICP 备案，开通即可用。这也是跨境独立站和外贸站常选香港的原因之一。
